# Reach

Reach is a top-down space god-game with no avatar and no direct unit control: you cultivate a population by supplying resources, issuing directives, and clearing dangers, and it grows, spreads, and organizes on its own. Empires expand by influence rather than conquest, so borders are a living contest and no single power can steamroll the map.

## Running it

Download the latest build from the Releases page and run the executable — it is self-contained, with no installer or extra dependencies to set up. Any 64-bit Windows PC with working graphics drivers will run it; it uses the OpenGL compatibility renderer, so a modern or dedicated GPU is not required.
